# Financed protection

This repository is being restarted from its research question. The first
implementation explored confidence-sensitive credit and surprisal-based
issuance. It did not implement the more basic incentive loop the project
needed: a funded commitment causing a self-interested actor to perform costly,
effective protection.

Attempt 2 therefore begins without money creation. Its first milestone is a
small, fully funded protection contract with explicit actors, payoffs, resource
constraints, balance sheets, counterfactuals, and failure cases. Credit and
circulating money may be introduced only after that mechanism passes stated
economic and evidentiary gates.

## Attempt 1

The complete previous implementation is preserved at Git tag `attempt1` and
branch `attempt1-archive`, both pointing to commit `8e88597`. Its code, model,
results, prompts, references, and decision record remain available there.

Surprisal, exergy redemption, term structure, and perpetual claims are no
longer requirements. They are hypotheses that must demonstrate value over
simpler mechanisms before they return.

This is a toy research program, not a monetary proposal.
